# ONNX OCR Pipeline

A standalone OCR pipeline using ONNX models for text detection and recognition. No PaddlePaddle required.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run OCR on an image
python -m ocr_pipeline . image.jpg
```

## Installation

```bash
pip install -r requirements.txt
```

**Requirements:**
- Python 3.8+
- onnxruntime (CPU) or onnxruntime-gpu (GPU)
- numpy
- opencv-python
- pyclipper
- shapely

For GPU support (faster inference):
```bash
pip install onnxruntime-gpu
```

## Usage

### CLI

**From within the exported directory:**
```bash
cd exported_ocr_pipeline
python -m ocr_pipeline . image.jpg
```

**From parent directory:**
```bash
python -m exported_ocr_pipeline ./exported_ocr_pipeline image.jpg
```

**Process multiple images:**
```bash
python -m ocr_pipeline . img1.jpg img2.jpg img3.jpg
```

**Save results to JSON:**
```bash
python -m ocr_pipeline . image.jpg -o results.json
```

**Adjust detection parameters:**
```bash
# Increase detection resolution (for small text)
python -m ocr_pipeline . image.jpg --det-limit 1280

# Lower thresholds (detect more text, may include noise)
python -m ocr_pipeline . image.jpg --det-thresh 0.2 --det-box-thresh 0.4
```

**CLI Options:**
| Option | Default | Description |
|--------|---------|-------------|
| `--det-limit` | 960 | Max side length for detection resize |
| `--det-thresh` | 0.3 | Detection binarization threshold |
| `--det-box-thresh` | 0.6 | Detection box score threshold |
| `-o, --output` | - | Output JSON file path |

### Python API

**Basic usage:**
```python
import sys
sys.path.insert(0, "./exported_ocr_pipeline")
from ocr_pipeline import OCRPipeline

# Initialize (loads models once)
ocr = OCRPipeline("./exported_ocr_pipeline")

# Run OCR
results = ocr.predict("image.jpg")

# Print results
for r in results:
    print(f"Text: {r['text']}")
    print(f"Confidence: {r['confidence']:.2%}")
    print(f"Box: {r['box']}")
```

**From within the exported directory:**
```python
from ocr_pipeline import OCRPipeline

ocr = OCRPipeline(".")
results = ocr.predict("image.jpg")
```

**Process multiple images efficiently:**
```python
ocr = OCRPipeline("./exported_ocr_pipeline")

# Single call with list of images
results = ocr.predict(["img1.jpg", "img2.jpg", "img3.jpg"])

# Or process in a loop (models stay loaded)
for image_path in image_list:
    results = ocr.predict(image_path)
    for r in results:
        print(f"{image_path}: {r['text']} ({r['confidence']:.2%})")
```

**Custom detection parameters:**
```python
ocr = OCRPipeline(
    "./exported_ocr_pipeline",
    det_limit_side_len=1280,  # Larger for small text
    det_thresh=0.2,           # Lower to detect more
    det_box_thresh=0.5,       # Filter weak detections
)
```

## Output Format

Results are returned as a list of dictionaries, one per detected text region:

```python
[
    {
        "text": "FN870HN",
        "box": [[27, 67], [252, 31], [262, 91], [37, 127]],
        "confidence": 0.9376
    },
    ...
]
```

| Field | Type | Description |
|-------|------|-------------|
| `text` | str | Recognized text |
| `box` | list | Four corner points [[x1,y1], [x2,y2], [x3,y3], [x4,y4]] |
| `confidence` | float | Recognition confidence (0.0 to 1.0) |

## Configuration

The `OCRPipeline` class accepts these parameters:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `model_dir` | (required) | Path to pipeline directory |
| `det_limit_side_len` | 960 | Max side length for detection resize |
| `det_limit_type` | "max" | Resize limit type: "max" or "min" |
| `det_thresh` | 0.3 | Detection binarization threshold |
| `det_box_thresh` | 0.6 | Detection box score threshold |
| `det_unclip_ratio` | 1.5 | Box expansion ratio |

## Troubleshooting

**ONNX Runtime warnings about unused initializers:**
These warnings are harmless and can be ignored:
```
[W:onnxruntime:, graph.cc:4885 CleanUnusedInitializersAndNodeArgs] Removing initializer...
```

**GPU not detected:**
If you see "CUDAExecutionProvider not available", the pipeline will use CPU. Install `onnxruntime-gpu` for GPU support.

**No text detected:**
- Try lowering `det_thresh` (e.g., 0.2)
- Try lowering `det_box_thresh` (e.g., 0.4)
- Increase `det_limit_side_len` for images with small text
